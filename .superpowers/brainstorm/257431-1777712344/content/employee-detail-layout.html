Layout de la ficha del empleado

¿Cómo debería estar organizada la pantalla principal de gestión de un empleado?

A — Página completa con tabs

Header del empleado + tabs horizontales + secciones apiladas. Sin lista lateral. Accedes desde el directorio.

B — Master-detail (actual)

Lista de empleados a la izquierda siempre visible + detalle con tabs a la derecha. Patrón Outlook/Gmail.

C — Panel de identidad + secciones

Columna izquierda fija con datos clave + nav. Columna derecha con el contenido en grid de campos.
