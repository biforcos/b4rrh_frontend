A — Canvas / Grafo visual

Los conceptos son nodos en un canvas. Arrastras conexiones entre ellos para definir operandos y feeds. Como n8n, Zapier o un shader editor. Muy visual, ideal para entender el flujo de cálculo de un vistazo.

Mejor para: Diseñadores de nómina que quieren entender y modificar el grafo completo
Riesgo: Más complejo de implementar; el grafo puede crecer mucho

B — IDE / Panel dividido

Lista de conceptos en árbol a la izquierda, panel de detalle a la derecha. Panel de propiedades estructurado con dropdowns y selectores de operandos. Interfaz familiar tipo "configurador".

Mejor para: Usuarios técnicos que trabajan con muchos conceptos frecuentemente
Riesgo: Puede volverse un formulario aburrido sin orientación visual

C — Wizard guiado

Flujo paso a paso para crear un concepto: tipo de cálculo → operandos → feeds → asignación de elegibilidad. Muy orientado a tareas. Ideal para primeros usos o configuradores ocasionales.

Mejor para: Usuarios ocasionales, onboarding de nuevos configuradores
Riesgo: Lento para modificaciones frecuentes; no da visión de conjunto

Mi recomendación: B+A — Panel IDE como base para el trabajo diario, con un panel de grafo integrado que muestra las dependencias en tiempo real a medida que configuras. El wizard puede ser el flujo de "nuevo concepto".
